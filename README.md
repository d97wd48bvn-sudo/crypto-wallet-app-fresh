                # Ethereum Wallet App

A React + ethers.js wallet app with:
- MetaMask connection
- ETH balance display
- Send ETH flow
- Recent transaction history
- Seed phrase import
- Network switching

## Run locally
```bash
npm install
    npm run dev
```

## Notes
- Use MetaMask in the browser to connect a real wallet.
- This app defaults to a safe testnet flow for experimentation.
